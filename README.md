# تک‌راه — TakRah 🚀

مسیر تو به دنیای تکنولوژی — مرجع فارسی‌زبان آموزش تکنولوژی

وبلاگی ساده، سریع و سئوشده برای فارسی‌زبانان؛ ساخته‌شده با Next.js (App Router)، Tailwind CSS و فونت وزیرمتن (سلف‌هاست).

## ✨ امکانات
- ۶ دسته‌بندی: هوش مصنوعی، موبایل، امنیت، نرم‌افزار، ابزارهای وب، برنامه‌نویسی
- صفحات استاتیک اختصاصی برای هر مقاله (SSG) با متادیتای کامل OpenGraph / Twitter / JSON-LD
- سایت‌مپ و robots.txt پویا
- دارک مود، جستجوی زنده، نوار پیشرفت مطالعه، فهرست مطالب
- آماده برای گوگل ادسنس (جایگاه‌های تبلیغ + ads.txt) و آنالیتیکس

## ⚙️ متغیرهای محیطی (در Vercel → Settings → Environment Variables)
| متغیر | توضیح | مثال |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | دامنه نهایی سایت (بعد از خرید دامنه) | `https://takrah.ir` |
| `NEXT_PUBLIC_GA_ID` | شناسه Google Analytics 4 | `G-XXXXXXXXXX` |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | کد تایید سرچ کنسول (روش متا تگ — اختیاری) | `abc123...` |

شناسه ادسنس بعد از تایید در `src/lib/site.ts` → `adsenseClientId` قرار می‌گیرد.

## 🚀 اجرای محلی
```bash
bun install
bun run dev
```

## 📦 دیپلوی
Push به شاخه `main` → Vercel به‌صورت خودکار دیپلوی می‌کند.
