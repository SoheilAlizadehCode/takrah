# جعبه‌ابزار فروش تکره (Sales Kit)

این پوشه «مصالح فروش» تکره است — هر چیزی که برای تماس با کلینیک‌ها، دایرکت اینستاگرام و فوروارد واتساپ لازم داری. آخرین نسخه همیشه روی همین شاخه `main` است.

## محتویات

| فایل | چیست | کِی استفاده کن |
|---|---|---|
| `takrah-onepager.pdf` | برگه معرفی A4 با QR زنده به takrah.top | چاپ و تحویل حضوری به مطب/کلینیک؛ پیوست ایمیل |
| `takrah-onepager.png` | نسخه تصویری همان برگه | فوروارد در واتساپ/دایرکت — سریع‌ترین راه ارسال |
| `takrah-onepager.html` | سورس قابل‌ویرایش برگه (QR بیس۶۴ داخلش است، خودکفا) | تغییر قیمت/متن → مرورگر باز کن → Ctrl+P → PDF |
| `takrah-sales-kit.pdf` | کیت فروش ۵ فصلی — نسخه PDF | مطالعه روی موبایل؛ فوروارد به همکار |
| `takrah-sales-kit.docx` | همان کیت، قابل‌ویرایش در Word | ثبت تجربه‌های خودت بعد از هر تماس؛ نسخه‌بندی شخصی |

## نقشه کیت فروش (۵ فصل)

1. استراتژی و قواعد طلایی (تعویض نام محصول، هم‌پیمانی منشی، دمو به‌جای توضیح)
2. سناریوی ویدیوی دمو (۴۰ ثانیه‌ای)
3. متن‌های آماده دایرکت و واتساپ برای دکترها
4. اسکریپت تماس تلفنی + جدول مدیریت اعتراض‌ها
5. سیستم پیگیری (ترتیب اثر) و قواعد QR / پایلوت

## نکته مهم قبل از ارسال

- قیمت‌ها را قبل از هر ارسال با جدول «جدول ۱ — کانال‌های فروش» در کیت چک کن؛ اگر تغییر کرد، در `takrah-onepager.html` هم اصلاح کن.
- QR روی برگه به `https://takrah.top` اشاره می‌کند — اگر آدرس دمو اختصاصی خواستی، سورس HTML را ویرایش و دوباره خروجی بگیر.
- پایلوت اول: ۲ هفته — هدف فقط گرفتن یک جمله مرجع قابل‌نقل است، نه سود.

## ساخت دوباره (Regenerate)

```bash
# PDF برگه معرفی از HTML (روتر poster اِسکیل)
node "$PDF_SKILL_DIR/scripts/html2poster.js" takrah-onepager.html --output takrah-onepager.pdf --width 720px

# PDF کیت فروش از Word
soffice --headless --convert-to pdf takrah-sales-kit.docx --outdir .
```

فونت نمایش در لینوکس: Tahoma به Vazirmatn نگاشت شده (`~/.config/fontconfig/fonts.conf`) تا خروجی PDF فارسی تمیز بماند.
